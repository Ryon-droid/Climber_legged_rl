# STM32 / STM32Cube.AI

部署芯片已确认：STM32H723VGTX，推理运行时计划采用 STM32Cube.AI。首轮计划为：PC/GPU 训练 PPO → 导出 float32 确定性 actor 为固定形状 ONNX → Cube.AI 转换/验证 → STM32 推理。训练用 critic 和优化器不部署。

- 策略目标 100 Hz，底层反馈控制目标 1 kHz，需按具体 MCU 和 CAN 预算验证。
- 候选 actor：按已确认的 4 台腿部电机，当前观测方案为 24 维单帧输入、6 维输出，MLP `[128,64,32]`，ReLU；计划顺序为左前、左后、右前、右后、左轮、右轮。后部链轮为 20:20；右轮导出映射及反馈轴/方向/零位仍待对齐。
- 先保持 float32，完成 PyTorch/ONNX/Cube.AI/板端输出比较，再评估量化。
- 固件剩余可用 RAM/Flash、Cube.AI 版本、电机/IMU 协议和实测延迟待补；内存预算需扣除现有固件占用。

详见 [参考参数与STM32部署](../docs/参考参数与STM32部署.md)。当前目录没有已实现的 MCU 适配器或固件，导出脚本仍是占位。
