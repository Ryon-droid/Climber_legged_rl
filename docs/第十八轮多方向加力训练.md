# 第十八轮多方向加力训练

准备日期：2026-10-31，北京时间。用户要求下一轮扩大方向覆盖并明显增加推力；正在运行的第17轮没有停止或替换。

后续已加入评估提速：4进程并行，确定性actor完全相同时复用原种子结果；回合数量和标准不减。相同16回合基准串行50.36秒，常驻四进程13.84秒，结果完全一致。整轮提速幅度仍取决于采样与更新耗时。见[训练提速验证](训练提速验证.md)，最新验证报告speed_validation_summary.json。

## 设置

配置：configs/robot/cad_getup_stand_round18_multidirection.yaml。

原设置已经包含世界坐标水平方向360度均匀随机推力。新增可选的八扇区采样，每回合随机洗牌、每八次推扰覆盖前后左右和四个斜向，扇区中心加正负10度随机偏差；回合只有一两次推扰时不能保证本回合完整覆盖八向。另增加正负15度仰俯角，形成小幅斜向上、斜向下的推力。方向定义仍为世界坐标。

| 参数 | 第17轮 | 第18轮 |
| --- | --- | --- |
| 抽取推扰回合概率 | 25% | 60% |
| 总力幅值 | 2–5 N | 8–40 N，混合档位 |
| 持续时间 | 0.05–0.10秒 | 0.08–0.15秒 |
| 两次推起点间隔 | 8–12秒 | 6–9秒 |
| 方向 | 水平360度随机 | 八扇区洗牌加抖动、仰俯角±15度 |
| 请求训练步数 | 120000 | 240000 |

每次推扰独立抽档：50%概率8–15 N、35%概率15–25 N、15%概率25–40 N。这是固定混合难度分布，不是随训练步数自动晋级或保证恢复率达标后才升级。最高力是原5 N的8倍，最长单次冲量由0.5 N·s增至6.0 N·s；绝大多数脉冲低于最高档。force_N表示三维合力幅值，仰俯角不会额外增加总幅值。

推力仍作用在主体质心，通过MuJoCo外力进入真实动力学，不直接写入速度。没有添加偏心施力或单独扭矩。站稳判定后再等3秒施力；推扰恢复期限4秒、连续稳定0.5秒。原有无扰验收、气弹簧155–220 mm、质量、几何和力矩限幅不改。

40%回合保持无推扰。困难初态训练抽样、成功轨迹回放、失败actor更新撤回和独立无扰选模均保留；强制受推选模每组由5增至8回合。PPO学习率和探索标准差没有同步放大。训练步数增加意味着本轮时间更长，不能承诺学习收敛更快；是否有效要看实际受推恢复和保留更新数量。

## 准备验证与局限

使用已评估的第16轮best做8个站姿、8个固定起身回合的强制推扰探测，种子100600起：站姿2/8通过，11次推中5次恢复；起身后抗扰4/8通过，13次推中9次恢复。它是新训练难度的基线，不是第17轮终评或第18轮训练成绩。该批次随机采样没有抽到25–40 N档，不能用这16回合证明已验证最高档恢复能力。

另外1000个种子的采样检查覆盖八扇区，三档出现486/363/151次，实际总力8.01–39.95 N，正负竖向分量501/499次。采样验证证明力生成逻辑，并不证明机器人能承受这些力。

39项相关回归测试、模型生成、1000步smoke、物理模型哈希、策略迁移和36000样本成功回放数据验证通过。1024步PPO短跑完成两次更新，两次均因起身保护检查失败撤回；最终无扰起身检查通过，普通PPO可独立加载，参数有限且不带训练回放/检查器。短跑没有证明策略抗扰提升；正式训练若持续大量撤回且受推评估不升，不能把新增步数当作有效训练进度。

下一轮命令固定从当前正在跑的第17轮best初始化。脚本会检查第17轮完整结束；不会自动中止本轮，也没有自动启动第18轮。第17轮best仍需完成后评估，此处第16轮基线不能替代该评估。

第17轮结束后，在项目根目录运行：

    cd /root/gpufree-data/Climber_legged_rl
    bash scripts/train_getup_round18.sh

日志继续显示剩余时间，保存在outputs/cad_getup_stand_round18_multidirection/。基线报告parent_probe.json、短跑validation/update_validation.json同在该目录。

默认旧配置不设置新增字段时，力仍为原来的水平随机脉冲，随机数调用顺序和力序列保持兼容。更改只对新配置显式启用；当前第17轮进程已加载原模块。以后若重新启动第17轮或其他带推扰旧配置，源文件哈希检查会要求重新prepare_getup和smoke，不能跳过检查或伪造哈希。
