# Climber 接口约定

训练、MuJoCo 和实机部署必须共享同一个接口。补齐模型后，把最终版本写进配置并固定以下顺序：

首轮候选接口已写入 `configs/robot/robot.yaml` 与 `configs/env/flat.yaml`：100 Hz 策略、腿部位置/轮部速度混合动作、单帧观测、STM32/CubeAI 部署。详细公式和参考来源见 [参考参数与STM32部署.md](参考参数与STM32部署.md)。关节映射与站姿仍待确认，尚未形成可执行接口。

- `joint_names`：主动关节顺序、正方向、零位和单位。
- `observation_names`：每一维的物理含义、坐标系、单位、scale、clip、噪声和历史帧顺序。
- `action_names`：策略输出的含义、scale、offset、限幅，以及下层 PD/力矩映射。
- 控制频率、仿真步长、decimation、观测延迟和动作延迟。
- reset 条件、终止条件、命令采样范围和评测指标。

策略导出前必须自动检查训练侧和部署侧的维度、顺序、scale 与限幅完全一致。不要靠手工记忆这些字段。
