## 路径诊断与局限

在同一 370 mm 后展趴姿、相同质量、450 N 气弹簧及 10/2 N·m 腿/轮限幅下，探测了 0.15–4 秒参考时长、零残差、相反腿残差、轮辅助等 24 组组合，均未取得完整起身；也试了先同向转动前后腿再收腿的参考，未取得完整起身。这说明简单改快参考不能解决当前问题；这些有限探测不能证明机器人在实物中或所有动态路径下无法起身。

原参考路径的部分压簧区间所需弹簧功大于理想电机功上界，但该比较没有计入轮做功、重力和惯性，因此只能定位当前参考的困难，不能作为机构不可行的证明。当前 450 N 恒力是假定曲线，未实测；链条仍按 20:20 直接传力，不能凭失败结果增加传动倍率。

## 第四轮：完整趴姿探索实验

配置：`configs/robot/cad_getup_stand_round4.yaml`。这是最多 100,000 步的探索试验，不是已验证有效的完整起身方案；正式训练未自动启动。

- 90% 完整后展趴姿、10% 站姿，关闭近站姿课程。每个完整趴姿回合仍要求起身之后站稳，同一策略连续控制。
- 学习率从 2e-6 改为 2e-5，动作标准差从 0.01 改为 0.15，clip 从 0.05 改为 0.1，重置优化器；目的是为新动作提供探索机会，不能保证越过当前压簧困难。
- 完整趴姿参考仍为原来的 4 秒 PD 路径，残差仍为 ±0.25 rad，因此动作空间/参考路径受限的问题仍可能存在。并没有把未成功的先抬腹路径写成已解决方案。
- 保留质量、惯量、闭链、155–220 mm 气弹簧行程、450 N 恒力、腿/轮 10/2 N·m 限幅、原地站稳判据和 20 秒回合。物理 XML 与第三轮逐字节相同。
- 推扰继续关闭。完整起身为零时不进入比赛碰撞训练。
- 50,000 步和结束时检查强制 `folded` 分组，不能用总 reward、混合成功率或站姿通过来替代。若 100,000 步后完整起身仍为零，停止机械重复续训，优先重做动力学可行的起身控制路径，并核实实际弹簧力曲线、安装方向与传动输出。
