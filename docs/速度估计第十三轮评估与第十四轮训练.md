## 第十四轮设置

保留本轮 best 作为父模型，目标是减少 PPO 更新带来的站稳退化，同时给成功恢复动作更多学习机会。这是针对停滞的下一轮尝试，尚无困难恢复成功率提升的证据。

| 参数 | 第十三轮 | 第十四轮 |
| --- | ---: | ---: |
| PPO 学习率 | 4e-6 | **1e-6** |
| 每 8192 次环境转移的回放更新 | 16 | **64** |
| 回放学习率 | 1e-6 | 1e-6 |
| 稳定/恢复轨迹采样占比 | 90% / 10% | 90% / 10% |
| 训练随机种子 | 142 | 143 |

继续使用第十三轮的 **15768 帧**成功数据，其中稳定帧 13740、恢复帧 2028；困难初态覆盖前 4 秒，受推轨迹包含恢复后的稳定尾段。无需重新采集。回放 batch 256、梯度限幅 1，起身与速度估计器继续冻结，运行时仍由单个 actor 输出六电机动作。

PPO 保持 1 epoch、clip 0.02、target KL 0.001、rollout 1024、8 个 CPU 环境和 8 个选模 worker，每 40000 步评估。目标 240000 步，完整 rollout 后约 245760 步。优化器重新初始化。

推扰仍为 **2–15 N、50–100 ms、八方向**。质量、气弹簧、电机限幅、物理、奖励及原来的 5 cm / 5°验收均沿用；先处理当前难例再扩大推力。

另做了仅成功轨迹回放的 1024 次优化诊断，损失下降，但两个诊断 checkpoint 的三个旧难例仍均 0/3；诊断站姿 4/5、固定起身 1/1。没有把这些诊断 checkpoint 用作下一轮父模型。记录位于 `outputs/cad_balance_estimator_round14/diagnostics/`。
