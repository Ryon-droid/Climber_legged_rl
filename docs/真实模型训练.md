## 工作顺序

1. **模型运动核验**：逐关节检查CAD零姿态、正向、被动闭链、装配分支和干涉，重点处理左侧运动不一致、气弹簧可伸缩自由度、六通道驱动映射。复现已提供的135 mm髋轮垂距；数值初值不等于编码器零位。
2. **动力学修正和站立训练**：从CAD材料/装配计算或测量补全每个刚体质量、COM和完整惯量。总计对上15 kg及每侧5.14 kg（含轮、电机、链条，不能重复加）。依据真实安装点/行程/力曲线建气弹簧，补上自由基座、真实六路驱动、轮胎/连杆接触和输出限幅。通过掉落、单通道、静载、短时稳定性检查后，再从零训练站立；不续用近似模型checkpoint。
3. **板端输出一致性验证**：同一输入比较观测预处理、float32 actor输出、动作缩放/偏置、反馈转换、PD/速度环及限幅。PC/导出运行时/Cube.AI/板端分别留版本和误差报告。软件数值通过不等于电机方向已验证。
4. **架空限力测试**：先完成传感器/编码器和单电机映射，用实测低上限逐路检查方向与停机，再六通道联动。
5. **带保护的落地测试**：前阶段通过后在保护架/系绳与急停下测试，先零指令、短时、低限幅，再逐步放宽。

必须实测的零位、方向、反馈比例和限幅另见 docs/实机必测清单.md 与 configs/robot/hardware_calibration.yaml。离线CAD运动核验不依赖板端编码器标定；真实站立动力学需要的刚体和气弹簧数据仍必须落实。

## 用左右对称缩小修正范围（2026-10-27）

用户再次确认实物底盘左右对称。对称关系作为CAD核对依据；不能认为导出右侧已正确，或直接复制其质量。

运行 python scripts/check_cad_symmetry.py 可生成 outputs/cad_model/symmetry_report.json，列出11组按机构功能提出的对应体及父子关系、分项质量和零件数量。对应关系用于核查，不是已经认证的逐件映射。

已发现的具体拓扑差异：左侧 base_splink 挂在 left_link1，base_spring link 2 挂在 left_link2；按机构角色对应，右侧 right_spring_link2 与 right_spring_link1 却都挂在 right_link1。右侧局部电机扫描通过，不能证明气弹簧真实跨接关系正确；需要按实际连接建立对称且有伸缩自由度的两侧机构。closure_008在装配描述中使用candidate锚点，也是需要核对的导出证据。

对称能减少重复工作：确定一侧真实连接、刚体归属及物性后，可以按镜像坐标变换建立另一侧，并独立核验；不能照抄坐标符号、惯量交叉项或关节正方向。总质量不因此自动补齐：即使将较重侧导出总质量同时用于两侧，保持原中央体质量，总计也仅约8.0304 kg，不是15 kg。该数值只是说明简单复制不能解决缺失，不应用于模型。

可以由软件与现有CAD继续完成的工作：逐件归属比对、关节/闭链镜像检查、轮胎几何提取、运动扫描和训练接口修复。需要真实依据的工作：至少一侧完整刚体物性、气弹簧端点/行程/力曲线；这些可来自CAD装配质量属性、厂商资料或测量，不必全由现场重新测量。六路电机零位、方向、反馈比例和实际限幅仍逐路测量。当前不要求重新确认已记录的15 kg、5.14 kg/侧和135 mm站姿。
