## 第八轮调整

配置：`configs/robot/cad_balance_estimator_round8.yaml`。本轮改为 **混合难度的初态课程**，优先扩展困难站姿附近的稳定范围，并保留完整难例训练与选模。

| 参数 | 第七轮 | 第八轮 |
| --- | --- | --- |
| 父模型 | 第六轮 best | **第七轮 160000 步 best** |
| 目标步数 | 240000 | **240000**，实际约 245760 |
| 已知困难推扰重置概率 | 30% | **15%** |
| 已知困难推扰训练/选模 seeds | 261106 | **261106、261704** |
| 其余回合内困难站姿概率 | 30% | **50%** |
| 困难站姿集合内 261409 权重 | 50% | **80%**，其余 12 个平分 20% |
| 困难站姿初态 | 始终完整噪声 | **25% 完整噪声，75% 从 50%–95% 均匀抽取噪声倍率** |

期望 reset 分布约为：15% 已知困难推扰、42.5% 困难站姿、31.875% 普通站姿、10.625% 固定趴姿。困难站姿集合中仍有完整难例：约占全部自动 reset 的 10.625%；完整 261409 约占全部 reset 的 8.5%。这些是重置概率，实际步数比例会受回合长度和提前失败影响。

新配置 `training.hard_standing_resets.initial_state_scale_range` 和 `full_state_probability` 只影响训练工厂的自动困难站姿 reset。它临时缩放初始倾角和基座速度的噪声，reset 完立即恢复原配置，异常时也恢复；不修改质量、动力学、关节姿态、动作、奖励或成功判定。显式 seed/options 绕过该采样；独立评估及所有选模组继续使用原始完整初态。原有配置没有这两个参数时保留原随机序列。

这不是按训练步数自动晋级的阶段课程，而是把容易到接近完整的初态和完整初态持续混合。它是否能扩大稳定范围，需要下一轮按完整难度验证。261704 从本轮独立复测发现后被纳入第八轮训练/选模，下一轮应再次使用新种子检查泛化。261700、261718 的起身后受推失败仍是未解决缺口。

沿用第七轮的姿态与其他恢复奖励、五帧历史、冻结起身和估计器、学习率 2e-6、1024 步 rollout、GAE 0.995、2 epochs、动作标准差、电机限幅及气弹簧。推扰仍为 **2–15 N、50–100 ms、八个水平扇区、垂直 ±15°**。各组成功率优先选模、保持验收和推扰恢复要求不放宽。

CPU 物理继续 8 环境，每 40000 步以 8 进程选模，日志保留预计剩余时间。
