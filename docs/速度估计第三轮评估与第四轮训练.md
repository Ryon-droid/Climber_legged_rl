使用新种子 **261300–261319**，每组 20 回合、最长 20 秒，分别强制站姿/固定趴姿、无推扰/2–15 N 推扰，配对比较：

所有受推组的 20 回合都实际受到推扰；所有组均无动力学警告。固定趴姿的无推扰轨迹起身约 **2.60 秒**，整段最大位移 **38.40 mm**、最大偏航 **4.88°**。这些起身重复使用同一个固定姿态和零初速度，不是 20 种不同倒地姿态；推扰在起身完成后施加，尚未验证起身中受撞或侧翻自救。

best 无推扰站姿组最大位移 13.25 mm、最大偏航 3.13°；final 分别增大到 **86.35 mm、21.41°**。final 这些站姿回合均运行到时间上限，但部分不满足站稳/恢复验收，不能将“没提前倒地”当作合格站稳。训练选模的已见困难站姿组，也由初始 **12/12** 降到后期 **7/12**。

已知 seed 261106 的第二次脉冲约 **14 N、90 ms**，世界方位 177.09°、向下 9.87°。best 受推后约 16.2 秒触地，而 final 能通过这个样例。说明更新确实改变了抗推行为，但同时损失了普通站稳和困难站姿能力，不能用 final 整体替换 best，也不能因新种子组 20/20 就认定全部 2–15 N 推扰都可靠。

## 第四轮设置

配置：`configs/robot/cad_balance_estimator_round4.yaml`。继续用当前估计速度反馈，同时冻结起身分支和速度估计器；训练站稳分支、critic 及动作分布参数。

| 项目 | 第三轮 | 第四轮 |
| --- | --- | --- |
| 父模型 | 第二轮 best | 第三轮 best，确定性 actor 与第二轮 best 相同 |
| 目标步数 | 120000 | 120000，8 环境下实际约 122880 |
| PPO 学习率 | 1e-5 | **5e-6** |
| clip / target KL | 0.02 / 0.0015 | **0.01 / 0.0008** |
| 已知失败推扰采样 | 随机遇到 | **20% 回合重置到 seed 261106 的站姿并强制启用原有推扰** |
| 较大偏移的恢复奖励 | 关闭 | **启用已有 Huber 恢复惩罚** |
| 已知失败推扰选模 | 未单列 | **单列强制受推组** |

新增 `PushResetReplay` 只包裹训练环境的自动 reset。它重放真实物理站姿和原有随机力脉冲，不修改状态来帮助恢复，也不注入教师动作；显式 seed/options 的 reset 和独立评估不会进入训练采样。临时强制启用该回合推扰后立即恢复原配置。实测训练采样的初态、逐步状态和两次力脉冲，与独立强制受推评估完全一致。

第四轮期望回合分布约为：**20% 已知受推站姿、16% 困难站姿、48% 普通站姿、16% 固定趴姿**。其余回合仍以 40% 概率启用原有推扰，总体约 52% 回合启用推扰；启用不代表一定活到首推。2–5 / 5–10 / 10–15 N 概率仍为 50% / 30% / 20%，持续 50–100 ms，八个水平扇区，垂直方向 ±15°。

Huber 惩罚在完成起身后生效，对位置、速度、航向和偏航速度给出随误差持续变化的惩罚。它与原有精确站稳奖励同时使用，目的是让机器人在偏移较大时仍有恢复信号；是否有效需要下一轮结果验证。

选模优先级为：普通起身/站稳成功、起身完成、困难站姿成功、原有随机受推组成功，然后比较已知困难推扰成功，最后比较奖励。这样不会仅凭解决一个已见推扰样例而接受普通站稳退化。seed 261106 已成为训练与选模样例，下一轮仍需使用新的种子做独立复测，不能把该样例当成泛化证据。

物理模型、质量、六闭链、气弹簧、电机限幅及现有 5 cm/5°保持验收沿用第三轮；受推暂态及恢复期限也沿用原有设置。仍使用 CPU 物理 8 环境、每 20000 步以 8 进程选模，日志保留预计剩余时间。
