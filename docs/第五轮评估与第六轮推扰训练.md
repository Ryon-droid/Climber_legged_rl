## 推扰基线和实现

已加入可关闭的外力推扰，旧配置默认不启用，旧策略回放仍按保存配置。物理 XML 与第五轮一致，不改变质量、关节、弹簧、摩擦和电机控制；观测仍为 30 维，不给策略直接输入推力大小或方向。

基线测试均为 15 秒确定性运行、每回合强制安排一次水平推力，首次在 3 秒开始，持续 0.1–0.2 秒：

- 0.5–2 N，种子 94000–94011：12/12 存活并恢复。
- **2–5 N**，种子 94000–94007：8/8 存活并恢复。

第二组初态与第一组部分重合，不是另一份完全独立泛化集合。受测推力来自给定区间随机采样，不是穷尽所有方向/幅值。小推力的通过只证明已测的短脉冲能力，尚不能推断比赛冲撞能力。

基线报告位于 `outputs/cad_dynamics_round6_push/round5_best_push_baseline.json` 与 `round5_best_2to5N_baseline.json`。原力强度为仿真课程设置，不是已确认的比赛要求。

实际推扰为通过 `data.xfrc_applied` 施加于 base 刚体质心的世界坐标水平力，无额外外加力矩；持续期按控制周期量化，结束后清零，不直接改基座速度，不修改气弹簧施力。当前不覆盖偏心碰撞、斜向/竖向推力或真实碰撞接触。

## 第六轮配置与验收

`configs/robot/cad_dynamics_round6_push.yaml`：

- 从第五轮 **best/best_model.zip** 开始，新增 **200 万步**，单回合 30 秒。
- **70% 回合**随机水平推扰、30% 不推扰；2–5 N，持续 0.1–0.2 秒，首推在 3 秒，后续间隔 8–12 秒。每回合末尾保留完整恢复窗口，不安排无法评价恢复的末秒推力。当前强度不自动升级，需独立评估后再提高。
- 学习率 **3e-5**，探索 std **0.035**；沿用第五轮的位置、朝向、腿长目标和奖励。
- 允许推扰期间临时偏移，但整回合最大偏移限制为 20 cm、最大朝向偏差 20°；每次撤力后 **4 秒内**，位置≤5 cm、朝向≤5°、移动速度≤0.05 m/s、转向速度≤0.05 rad/s、倾角≤5°须连续保持至少 **0.5 秒**，且回合结束时仍在这些范围内。位置和朝向始终相对初始参考，不把推偏后的位置重设为目标。
- 无推扰回合继续使用原来的严格原地标准。报告同时保留 `stationary_success_fraction` 与 `push_recovery_success_fraction`；后者在混合回合中包括无推扰成功，必须结合 `push_episode_count`、`pushed_episode_success_fraction` 和每次推扰记录判断，不能把未受到推力的回合当成抗推证据。
- 训练日志开启推扰时 `eval/success_rate` 表示相应任务成功；`push_metrics` 保留推力、持续时间、冲量、推扰次数及恢复情况。恢复时间包含要求的连续 0.5 秒稳定保持，最短值约 0.5 秒，不能说成瞬时恢复。

51 项测试通过，覆盖推力持续时间、关闭清零、种子可复现、未完整恢复失败、仿真动力学响应、旧策略观测兼容等。构建和 2000 步 smoke、训练准备检查通过。0.5–2 N 先行短跑通过后，最终 2–5 N 配置另作 8192 步流程验证；短跑仅检查工程通路，不作为学习效果提升证据。最终 2–5 N 配置的 8192 步流程验证已正常完成，确认保存和末尾评测可运行；自动评测是短跑工程验证，不作为相对原策略的泛化提升证据。
