# 第一版训练计划

## P0：模型加载

只加载机器人和地面，不训练。检查关节方向、静态姿态、质量/惯量、接触几何、关节限位和闭链约束。

## P1：平地基线

只保留站立、高度/姿态、低速线速度和角速度跟踪、动作平滑、力矩/关节限位等奖励。先关闭大范围随机化，使用普通 PPO 和 MLP。

## P2：真实动力学对齐

用架空单关节轨迹或真机日志校准执行器、摩擦、阻尼、力矩限幅、控制延迟和闭链耦合。所有测得范围记录到配置，而不是散落在代码里。

## P3：鲁棒性

逐项加入摩擦、质量/质心、惯量、PD、动作延迟、观测延迟和外力随机化；每次只改一个因素并保留对照实验。

## P4：粗糙地形和高动态动作

先坡面和小障碍，再台阶/飞坡/跳跃。跳跃任务采用参考轨迹或阶段性稠密奖励，不直接依赖单个最高点奖励。

## P5：sim2sim 与实机

导出策略，在 MuJoCo 中逐项对齐输入输出和闭链处理；通过固定测试集后再进行架空实机、低速平地、逐步增加速度和地形的验证。
