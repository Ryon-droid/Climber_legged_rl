# 链轮传动与气弹簧参数

用户已确认：每侧两台 8009P，前部 link1 直驱、后部 linkrear1 通过链轮驱动；共四台 8009P、两台 3508。主动、从动链轮均为 20 齿，额外比 1:1；按 9:1 减速器后接链轮，总比 9:1。左右实物对称。气弹簧规格原文为 `15*6/95*65*450N`。暂按 15 mm 缸筒外径、6 mm 活塞杆直径理解；95 和 65 的长度定义未确认，不据此推算行程或安装中心距。

## 链轮传动首先需要什么

| 信息 | 怎么提供 | 用途 |
|---|---|---|
| 被驱动轴（已收到） | 后部 linkrear1；XML 左 left_link_rear_1_joint、右 right_rear_link1_joint | 确定施加驱动力矩的位置，电机本体不必直连连杆 |
| 主动链轮齿数 Z1（已收到） | 20 | 计算额外链传动比 |
| 从动链轮齿数 Z2（已收到） | 20 | 额外比 1:1，不额外放大理想力矩 |
| 方向 | 电机反馈正向转动时，对应模型关节是正向还是反向；左右分别标定 | 确定每路的 +1/-1，镜像不能代替符号标定 |
| 反馈轴 | 协议位置/速度来自电机转子、9:1 减速后输出轴，还是链轮后的连杆轴 | 避免重复除减速比 |
| 零位、站姿、限位 | 一张规定站姿图及对应编码器读数、连杆角度，可先提供原始数据 | 确定偏置与闭链可达范围 |

链条型号/节距、链轮中心距、张紧方式、回程间隙、效率及转动惯量建议后补。理想传动第一步可按无间隙刚性传动建立，但必须显式标注假设，后续用实测校准。一般不需要把每节链条都建进强化学习模型；保留正确的传动映射和驱动位置即可。

单级、固定传动比，且链轮装在 8009P 的 9:1 减速器之后时，定义：

- `i_chain = Z2 / Z1`，`i_total = 9 * i_chain`；多级则把每级传动比相乘。Z1/Z2 必须按安装轴识别，不能按链轮大小猜。
- 转子反馈：`q_joint = s * (theta_rotor - theta_rotor_zero) / i_total + q_joint_zero`；`dq_joint = s * omega_rotor / i_total`。
- 减速器输出轴反馈：上式的角度/速度除数只用 `i_chain`；若已是连杆轴反馈，则不再除机械减速比。
- 正向驱动的理想力矩换算：`tau_joint ≈ s * eta_chain * i_chain * tau_gearbox_output`；若从转子力矩换算，还需 9:1 减速器及其效率。回驱和静摩擦另行建模。

`s` 是模型坐标下的方向符号；`eta_chain` 为链传动效率，尚未实测。策略和反馈 PD 均以被驱动模型关节为参考，再换成驱动器指令；不额外增加一维链轮动作。20 N·m 是用户给出的额定值，需确认是转子、9:1 输出轴还是链传动后的关节轴，不能重复乘减速比，也不能直接充当峰值限幅。

## 气弹簧还需要什么

450 N 是标称轴向力，不是刚度，也不代表所有行程/温度下都恰好等于 450 N。规格中的 `15*6` 暂按缸筒外径 15 mm、活塞杆直径 6 mm 记录；如供应商采用不同顺序或定义需更正。`95*65` 暂保留为两项长度数据，须确认分别指伸出/压缩长度、安装长度/行程，还是其他尺寸后才能建立几何模型。

用户后续截图已标出左侧气弹簧组件：`base_splink` 与 `base_spring_link2`；后者通过设计关节 `base_spring_link2_joint` 挂在 `left_link2` 下。当前 XML 的候选对应项是 `left_link_spring1` / `left_link_spring1_joint`，但名称、闭链编号与安装坐标尚需核验，详见 [机械笔记核对.md](机械笔记核对.md)。这部分连杆关系已收到，无需重复提供；具体孔位可优先从现有 CAD/模型提取后用尺寸核对。

目前收到规格字符串 `15*6/95*65*450N`，无需重复提供直径和标称力。还需确认：

1. 数量、每侧安装位置，是伸出推力型还是回拉型。
2. `95` 和 `65` 各自代表什么及测量基准；其中哪一个（若有）是行程，伸出/压缩时两端安装孔中心距分别是多少。也可提供规格页照片。
3. 左侧组件 link 和父节点已由截图补充；仍需核对组件两端安装孔位置及局部坐标，可从 CAD 提取。右侧按已确认的对称设计核查导出对应项。
4. 厂商力-行程曲线、450 N 对应的测量位置/温度、阻尼规格；没有曲线时先给型号，之后可测几组不同长度下的力。

气弹簧力沿两安装点的连线作用，产生的关节力矩取决于随姿态变化的力臂，不能用“450 N × 腿长”代替。已知方向、安装点和有效行程后，可以先单独验证标注为近似的恒力 450 N 模型；正式迁移前需评估力曲线、摩擦/阻尼、行程端点。当前仓库尚未实现该力模型，XML 的 connect 也不提供气弹簧力。
