# 208毫米限位起身适配结果

2026-11-06已完成固定趴姿的仿真起身适配。使用用户确认的气弹簧最大安装孔中心距208 mm，沿用最短155 mm、450 N恒力近似、原电机限幅和20秒完整回合验收标准。最终策略独立输出6路动作，运行时不使用示范动作、关节参考辅助或姿态跳转。

## 训练方法与结果

先在真实闭链动力学上搜索可成功起身的动作示范，再通过示范学习和DAgger训练起身分支。本轮没有进行新的PPO更新。DAgger包含示范策略标注的学生状态，其中失败回合状态也明确记录为学习数据，不当作成功演示统计。

训练共进行7000次监督更新，约44.1秒；只改变起身分支的8个权重张量，站立分支、速度估计器、价值网络、动作标准差及其余26项张量逐项一致。策略保存后重新加载，并在独立进程中通过原生观测直接运行，未保留示范时的输入修正。

| 新208 mm模型上的完整20秒测试 | 原策略 | 新策略 |
|---|---:|---:|
| 无推扰固定趴姿起身并站稳 | 0/20 | 20/20 |
| 起身后强制加入推扰 | 0/20 | 19/20 |
| 普通站立，无推扰 | 20/20 | 20/20 |
| 普通站立，强制推扰 | 20/20 | 20/20 |

新策略约3.64秒完成起身判定。推扰组种子355006仍在站起后的恢复中机身触地失败，因此不宣称所有推扰都已解决。另有4个既有困难站立回合，两种策略都失败；所有站立对照的成败、终止时间、最大位移和最大航向偏差逐项相同，没有检测到退步。

独立测试共168个回合，耗时约203.6秒，使用355000–355019的种子，与示范收集和模型选择种子分离。固定趴姿是同一个近乎确定的初始几何，20个种子不等于20种不同趴姿，也不证明对任意倒地姿态均能起身。

本次候选所有回合均无模拟器数值警告。气弹簧上限的最大数值穿透约0.357 mm；限位块采用数值接触近似，尚未测得真实刚度。尚未进行实机验证。
