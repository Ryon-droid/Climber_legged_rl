## 仍然存在的抗推缺口

额外复测上一轮发现的 seed **261106**：两轮 best 均在第二次约 **14 N、90 ms** 脉冲后触地，第二轮约 16.24 s 失败。该脉冲接近世界水平 177°、向下约 9.9°。这个已知失败样例不在上述新种子组内，不能因四组新种子均 20/20 就认定所有方向和时刻的 2–15 N 都已经可靠。

该对照保存在 `assessment/known_push_261106.json`。本轮没有直接扩大力的上限，下一轮增加现有推力范围的采样。

## 第三轮调整

第二轮即使降低估计器学习率，起身通过率仍反复变化。估计器是起身分支输入的一部分：只冻结起身网络、继续更新估计器，确定性起身仍可能改变。第三轮因此 **同时冻结起身网络和当前速度估计器**，训练站稳/交接分支、critic 和动作分布参数，仍使用现有估计速度，没有切回仿真真实速度。

这项冻结固定了名义初态下确定性回放的起身网络与速度反馈模型。训练时探索动作仍有随机噪声，站稳分支更新也可能影响起身后的保持，因此继续分别评估起身和完整站稳成功率。

新增可选设置 `training.velocity_estimator.trainable: false`，默认仍为 true，旧配置行为不变。冻结时继续报告速度误差，停止估计器优化；保存/加载会保留训练开关。同维度 warm start 也已支持将起身分支从可训练切为冻结，并保存对应 policy kwargs。

配置：`configs/robot/cad_balance_estimator_round3.yaml`。

| 参数 | 第二轮 | 第三轮 |
| --- | --- | --- |
| 父模型 | 第一轮 best | 第二轮 20000 步 best |
| 目标步数 | 200000 | **120000**，实际约 122880 |
| 起身分支 | 训练 | **冻结** |
| 速度估计器 | 每轮更新 | **冻结权重，继续使用估计值** |
| 趴姿 / 普通站姿 / 困难站姿重置比例 | 约 34% / 51% / 15% | **约 20% / 60% / 20%** |
| 有推扰回合比例 | 25% | **40%** |
| 2–5 / 5–10 / 10–15 N 采样概率 | 60% / 30% / 10% | **50% / 30% / 20%** |
| 选模受推评估 | 每种 reset 8 回合 | **每种 reset 16 回合** |

CPU 物理继续 8 环境；PPO 学习率 1e-5，clip 0.02，target KL 0.0015；每 20000 步以 8 进程评估。物理模型、质量、电机限幅、气弹簧、5 cm/5°保持验收和 2–15 N 推力上限沿用第二轮。

已通过新增冻结/重载单元测试及相关回归共 **39 项**。真实 CAD 短程验证使用 2 环境、512 步 PPO：起身和估计器权重完全不变，站稳权重有更新，起身时间前后均为 2.60 s，普通 PPO 推理加载和自定义训练恢复通过。模型生成、姿态库、各 1000 步零动作/随机动作 smoke 也通过。验证报告位于 `outputs/cad_balance_estimator_round3/validation/summary.json`；它只验证训练接线，不代表第三轮已经完成或取得收益。第三轮长训练未启动。

```bash

mkdir -p outputs/cad_balance_estimator_round3

  scripts/train_balance_history.py \
  --variant estimator_round3 \
  --num-envs 8 \
  --total-timesteps 120000 \
```
