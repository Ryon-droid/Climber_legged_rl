## 独立复测

本次重新使用 seed 261100–261119，每组 20 回合、每回合最长 20 s，分别强制站姿/趴姿，以及无推扰/实际施加 2–15 N 推扰。best、final 和预训练父模型使用配对种子。验收仍为 5 cm、5°及原速度标准。

| 场景 | 预训练父模型 | 第一轮 best | 第一轮 final |
| --- | ---: | ---: | ---: |
| 无推扰站姿 | 18/20 | **20/20** | 20/20 |
| 无推扰起身并站稳 | 0/20 | **20/20** | 0/20 |
| 站姿后受推并恢复 | 未复测 | **19/20** | 19/20 |
| 起身站稳后受推并恢复 | 未复测 | **20/20** | 20/20 |

趴姿使用同一个固定 CAD 姿态、初速度为零，无推扰时是同一条确定性轨迹的重复，不能理解为 20 种倒地初态。站姿有随机初始扰动；受推回合有不同方向、力度和时刻，受推组的 20 个回合均实际收到推力。推扰在起身站稳后施加，本次没有验证起身途中抗碰撞。

best 起身约 **2.09 s**，整段最大位移 **24.11 mm**、最大偏航 **4.62°**。final 起身约 **2.48 s**，最大位移 **30.81 mm**、偏航 **5.77°**：它能完成起身并活到 20 s，但偏航超过 5°，所以无推扰联合验收失败。受推场景允许配置中的瞬态偏移/转角并要求恢复，和无推扰全过程验收不同，受推通过不能抵消这个问题。

best 受推站姿失败的 seed 为 261106，第二次推力约 **14 N**，持续 **90 ms**，接近世界水平 177°并向下约 9.9°，随后在 16.21 s 触地。说明当前还不能认为所有 2–15 N 碰撞都可靠恢复。所有复测组均未出现仿真动力学警告。

结果在 `outputs/cad_balance_estimator/assessment_round1/quality_summary.json`；相同目录保存各组逐回合指标。best 在训练时的困难站姿固定组为 12/12，这些种子参与了训练和选模，属于已见组；独立成功率以上表的新种子为准。

## 为什么调整下一轮

第一轮训练中的起身通过率多次在 0 和 1 之间变化，final 又低于 best，尚未稳定收敛。原训练自动重置中约 6% 为趴姿、54% 为普通站姿、40% 为困难站姿，起身数据偏少。

另在原教师的整回合验证集上检查估计器保持情况：预训练起身帧 RMSE 约 **0.00669 m/s**，第一轮 best 为 **0.13975 m/s**；站姿帧则由 0.00551 变为 0.00500 m/s。这反映了原起身轨迹上的估计能力下降，与站姿数据占多数一致，不能单凭日志末尾的约 0.0026 m/s 训练误差判断完整起身估计质量，也不能据此断定是唯一失败原因。闭环 best 已适应了新的输入，但需要继续巩固。

第二轮配置为 `configs/robot/cad_balance_estimator_round2.yaml`：

| 参数 | 第一轮 | 第二轮 |
| --- | --- | --- |
| 初始化 | 监督预训练模型 | 第一轮 best，保持初始确定性动作 |
| 目标步数 | 120000 | 200000，按 rollout 实际约 200704 |
| 趴姿 / 普通站姿 / 困难站姿自动重置比例 | 约 6% / 54% / 40% | **约 34% / 51% / 15%** |
| PPO 学习率 | 2e-5 | **1e-5** |
| PPO clip / target KL | 0.03 / 0.0025 | **0.02 / 0.0015** |
| 估计器学习率 / 每轮 epoch | 1e-3 / 4 | **1e-4 / 1** |
| 腿 / 轮动作标准差 | 0.005 / 0.1 | **0.0025 / 0.05** |
| 评估间隔 / 进程数 | 10000 / 4 | **20000 / 8** |

起身和站稳分支均继续训练；总质量、几何、气弹簧、硬件限幅、5 cm/5°验收、2–15 N 推扰范围及采样概率沿用第一轮。CPU 物理继续使用 8 环境。第一轮 13 次选模评估共耗时约 856 s，日志到最后一轮约 927 s，评估占比很高；第二轮增加评估并行度并降低评估频次，实际总耗时仍以运行日志为准。

模型生成、姿态库、零动作/随机动作各 1000 步 smoke、artifact 校验和父模型迁移已通过；迁移后的初始确定性动作与 best 一致，确认估计器实际使用 1e-4、1 epoch。尚未启动第二轮长训练。
