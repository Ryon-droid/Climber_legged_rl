## 第十轮调整

配置：`configs/robot/cad_balance_estimator_round10.yaml`。保留已验证的分别裁剪梯度，适度增加探索和更新预算。本轮仍需通过完整训练检验收益。

| 参数 | 第九轮 | 第十轮 |
| --- | ---: | ---: |
| 父模型 | 第八轮 best | **第九轮 80000 步 best** |
| 目标步数 | 240000 | **400000**，完整 rollout 后约 401408 |
| 学习率 | 2e-6 | **1e-5** |
| 四个腿关节动作标准差 | 各 0.005 | **各 0.01** |
| 两轮动作标准差 | 各 0.1 | **各 0.2** |
| PPO clip | 0.02 | **0.05** |
| target KL | 0.0015 | **0.003** |

动作标准差是策略归一化动作空间的数值，不是直接施加的力矩。第十轮站稳阶段对应腿目标位置噪声标准差约 **0.0025 rad**，轮目标速度约 **2 rad/s**；电机最终仍受原控制器和输出限幅约束。实际探索标准差会随训练更新，表格为每轮开始时的值。

保持 2 epochs、1024 步 rollout、GAE 0.995、CPU 8 环境、8 进程选模及每 40000 步评估。继续冻结起身和估计器，保留困难初态混合采样、已见推扰回放、奖励与成功率优先选模。

**推扰不加大：仍为 2–15 N、50–100 ms、八个水平扇区、垂直 ±15°。**当前已有约 14 N 的明确失败样例，先学习这些工况再扩大力。质量、气弹簧、电机能力、固定趴姿、5 cm/5° 站稳门限和推后恢复验收均沿用。

第九轮日志中的裁剪前动作梯度范数均值约 60.74、价值梯度约 4886.84，分别裁剪确实执行，但成功率未提高。平均近似 KL 约 0.000308，PPO clip fraction 约 26.6%。第十轮增加探索和更新幅度是待验证的训练选择，不保证必然突破。

## 验证

相关 **26 项测试通过**，覆盖动作探索参数、迁移和分别裁剪梯度。真实 CAD 模型与姿态库生成、1000 步零动作及随机动作 smoke、512 步 PPO 检查通过，普通站姿/固定起身前后各 2/2。

另完成 **2 环境、8192 步、1024 步 rollout** 的真实训练工厂短试，使用第十轮动作标准差，覆盖第二次推扰。25 次实际优化步骤的动作/价值网络裁剪后范数最大约 **1.0000004 / 1.0000021**；起身与估计器保持冻结，站稳分支发生更新，临时 hook 正常清理，标准 PPO 回放和自定义恢复加载均正常。

300 次自动 reset 检查覆盖完整和缩小困难初态；参考环境 qpos/qvel 对照、原配置恢复及显式 reset 绕过采样均通过。短试后与第九轮 best 配对，普通无扰站姿新种子 262100–262104 均 **5/5**、固定起身均 **1/1**；三个已见难例两者仍 **0/3**。短试验证训练流程，不构成困难工况已改善的证据。
