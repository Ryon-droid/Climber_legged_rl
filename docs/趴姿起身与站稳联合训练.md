## 本轮任务

- 同一个 PPO 策略，六路电机输出，36 维观测；50% 回合从后展趴姿开始，50% 从站姿开始。
- 趴姿为腹部朝下、主体安装板水平、双腿和轮心向后延展；后展水平距离随机取 360、370、375 mm。
- 趴姿回合先起身，再保持站稳；总回合 20 秒，起身参考 4 秒，10 秒前需连续稳定 1 秒。
- 起身参考使用闭链 IK 轨迹的关节角路点和 PPO 残差。它是带参考的联合训练，不是完全无参考起身。轨迹只控制关节 PD 目标，动力学中不设置根部位姿。
- 成功要求两轮接地、主体离地、腿长误差不超过 10 mm、髋高误差不超过 15 mm、倾角/朝向不超过 5 度、位置偏移不超过 5 cm、平移和偏航速度分别不超过 0.05 m/s 和 0.05 rad/s。起身后仍使用初始位置/朝向作为目标。
- 保留 135 mm 站姿定义、质量、450 N 气弹簧标称力、155–220 mm 销轴中心行程、腿/轮 10/2 N·m 限幅。CAD 起身关节范围为显式仿真分支范围，尚不是实机测量的机械角限位。

## 初始化与评价

从第五轮原地站立 best 初始化，30 维输入扩展到 36 维，新输入权重为零，优化器重新初始化。迁移只允许已列出的十个 CAD 关节分支范围和两个气弹簧止挡变化；质量、惯量、力矩、弹簧力及其他 XML 变化均拒绝。

迁移前基线每类各 3 回合：站姿 3/3 成功，后展起身 0/3，约 5.21 秒倾覆。见 `outputs/cad_getup_stand/initial_policy_assessment.json`。几何可行不代表动力学能够起身，本轮是开始学习该能力，不能据此声称起身已通过。

加入腿长收缩的连续进度奖励，未起身时姿态/位置奖励按进度折减，避免只趴着保持水平获得高分。保留正的存活奖励，避免通过早倒缩短负回报。起身后恢复完整站稳奖励。

每 50,000 步分别强制测试 5 回合趴姿和 5 回合站姿；best 优先比较两组成功率的较小值，再比较平均成功率、起身达标率和回报。结果在运行目录的 `combined_evaluations.json`，日志也单列 `folded_success_fraction` 和 `standing_success_fraction`。训练结束分别各评估 10 回合，保存 `evaluation_by_reset.json`。

PPO：2,000,000 步、8 个并行环境、学习率 3e-5、动作标准差 0.15、clip 0.1、seed 61。训练日志保留 `time/remaining` 剩余时间；结束采样后状态为 evaluating，评估结束后才标记 completed。

正式启动前 70 项测试通过，零动作/随机动作各 2,000 步工程检查通过。8,192 步短程训练及两组独立评估完成：站姿 10/10，起身 0/10，均无仿真数值警告。短程运行 `cad_getup_stand_validation_20261029_1220` 仅验证训练通路，正式运行仍从第五轮 best 初始化。

## 启动与查看

正式运行名：`cad_getup_stand_20261029_1220`。已启动时不要重复执行训练命令。

```bash
cd /root/gpufree-data/Climber_legged_rl
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 /root/gpufree-data/.venvs/climber-validation/bin/python scripts/train.py --backend cad-dynamics --config configs/robot/cad_getup_stand.yaml --warm-start outputs/mujoco_runs/cad_dynamics_midpoint135_round5_stationary_20261028/best/best_model.zip --run-name cad_getup_stand_20261029_1220
```

实时日志：

```bash
tail -f outputs/cad_dynamics/cad_getup_stand_20261029_1220.log
```

在有桌面的终端运行 MuJoCo，首个 best 会在 50,000 步评估后生成：

```bash
MUJOCO_GL=glfw /root/gpufree-data/.venvs/climber-validation/bin/python scripts/play_getup.py --config configs/robot/cad_getup_stand.yaml --checkpoint outputs/mujoco_runs/cad_getup_stand_20261029_1220/best/best_model.zip --reset-mode folded --loop
```

把 `--reset-mode folded` 换成 `--reset-mode standing` 查看站稳，或 `mixed` 查看随机混合初态。回合内部由同一个策略从起身继续到站稳。

工程检查和短程训练通过只证明训练通路能运行；实际起身质量看两组独立评估及可视化。当前模型没有机器人内部自碰撞验收。
