# PPO 与小型世界模型起身实验

日期：2026-11-09。机器人仍为现有六电机闭链轮腿模型，气弹簧最大安装孔中心距 208 mm，最小 155 mm。策略 100 Hz，MuJoCo 物理步长 1 ms。

本实验是 SuperMimic 思路的小型适配，不是官方完整复现。使用现有 CPU MuJoCo 收集物理交互，使用 RTX 2080 SUPER 上的独立 PyTorch 环境学习世界模型和进行短期可微策略更新。保留原 PPO 环境。

本次三组训练统一不施加外部推力，以隔离起身问题；最终另外检查普通站立和推扰。PPO 沿用现有算法、起身奖励、学习率及动作分布，并非重跑所有历史课程设置。

## 三组对照

| 组别 | 学习方式 | 数据 |
| --- | --- | --- |
| 当前 PPO | 原 PPO 奖励、学习率和动作分布继续训练 | 原生仿真交互 |
| 轨迹 PPO | 相同 PPO，加参考跟踪奖励 | 同一组成功参考及原生交互 |
| 小型世界模型 | k=8 自回归动力学学习，H=16 可微策略更新，带价值函数 | 同一组参考、初始交互及新策略的在线交互 |

起点全部为第一轮保留策略，SHA256 `28a44dcfc15928016ec809137bade5b127a31a5f2cc880ee96ca590b5bf4c454`。只更新起身演员；站立演员、速度估计器保持原有权重。价值函数在各自训练方法中学习。

参考只选择当前机器人、当前 208 mm 限位下，无辅助 PPO 完整成功回合。失败和有噪声的有效回合保留给动力学学习。参考跟踪包含重力方向、主动腿角、虚拟腿长、髋高及航向，不强迫连续转动的轮子跟踪绝对角度。若某训练姿态没有成功参考，明确记录使用相邻姿态的参考。

## 预算和时间

每组最多 200,704 条新增仿真交互。参考 PPO 和世界模型组扣除已采集数据的全部 91,756 条交互，再使用剩余预算训练。数据中包含模型验证回合，对需要参考数据的方法采取保守的完整成本核算。

主耗时包括参考/交互数据采集、世界模型拟合、在线交互、策略优化及检查点选择。最终测试耗时另外报告。首次代码实现、调试及前期诊断拟合时间单独说明，不计为可重复训练流水线耗时。三组顺序运行，避免训练资源相互竞争。

## 隔离与验收

- 初始训练种子段 510000；世界模型验证 520000；检查点选择 530000；最终测试 540000。按完整回合划分，窗口不跨越重置。
- 初始数据 42 个训练回合、14 个完整模型验证回合。模型验证均衡抽取早期起身、后期起身、站立三个阶段。
- 预测检查包含 1、8、16、32 步。策略使用 16 步短预测。原 MuJoCo 根据预测 qpos 重算闭链及气弹簧几何，不能只相信模型预测的误差字段。
- 最终独立测试包含 48 个困难趴姿、8 个原始趴姿、16 个站立/推扰回合。旧测试几何配全新种子，不能称为全新几何泛化。
- 验收仍要求原来的腿长、高度、姿态、位置、航向、速度和连续稳定时间；不放宽为仅视觉上站起。
- 目标是困难趴姿至少 95%、原始趴姿全部成功、站立没有退步且没有数值警告。
- 原生测试仅调用策略网络；没有世界模型、参考跟踪控制器或示范动作替换。

这是单训练种子的筛选实验。即使某组更好，也需至少 3 个独立训练种子后才作稳定优越的结论。若未达到目标，只报告本预算内的结果，不给出虚构的达标时间。保留原策略，不自动替换、不部署实车、不自动追加训练。
