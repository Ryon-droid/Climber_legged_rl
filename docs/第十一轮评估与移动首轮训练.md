## 移动任务

新增独立配置 `configs/robot/cad_velocity_round1.yaml`，首轮为低速移动课程：

- 前进/后退目标范围±0.15 m/s，转向目标范围±0.3 rad/s；允许组合指令。这些是仿真课程范围，不是硬件额定能力。
- 20秒回合，前1秒先站稳，之后每4秒重新采样指令；1秒线性渐变，30%指令为零以练习停车。
- 移动时按机体前进速度、侧向速度和偏航速度跟踪奖励，不拉回起步位置。
- 松杆后在指令归零的位置建立停车参考，继续练原地站稳；不是要求移动后倒回出发点。
- 无推扰、无起身、无跳跃或小陀螺，全部6路动作由同一移动actor输出。

父策略选第五轮站立best，不使用最新起身final。沿用30维观测，零指令初始观测/确定性动作与站立模型一致；移动时停稳位置/朝向反馈置零，仍保留机体速度。只进行明确校验的155–220 mm气弹簧止挡迁移，质量/惯量、六闭链、站姿135 mm及原站立10/2 N·m控制限幅不变。已确认电机额定20/峰值40 N·m不意味着本轮擅自放大历史站立控制限幅。

新物理模型上的父策略基线共21回合、seed98700起：静止3/3，六种移动指令各3回合全部未达标，合计移动0/18；21回合都站满20秒。前后移动速度误差约0.15 m/s，转向误差约0.3 rad/s，说明它主要还在原地站立，并未学会按指令移动。不得用存活21/21称作移动21/21。[父策略基线](../outputs/cad_velocity_round1/assessment_parent.json)。

## MuJoCo回放

正式移动训练生成best后，在图形桌面终端打开最新正式移动run：

```bash
cd /root/gpufree-data/Climber_legged_rl
bash scripts/play_velocity.sh
```

默认按训练分布切换指令，终端打印速度指令。固定前进0.1 m/s并在第10秒松杆停车：

```bash
bash scripts/play_velocity.sh --command-forward 0.1 --command-yaw 0 --stop-after-seconds 10
```

`--command-forward -0.1`看后退，`--command-forward 0 --command-yaw 0.2`看低速转向。脚本不会把站立模型或512步验证权重伪装为已训练移动模型；刚生成的best也可能仍是父策略，须结合选模结果判断。当前准备完成不代表已有合格移动权重。
