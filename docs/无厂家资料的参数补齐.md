## 质量和惯量的获取顺序

1. 在原机械CAD中按“实际随同一个刚体一起运动”的零件组织装配。确认电机定子/转子、链轮、轮子、电池、线束等归属和计量口径。链条在现有导出中缺失，不能凭几何体积补回来。
2. 对各零件指定真实材料，电机/电池/气弹簧等复合件优先使用实物称重或可靠部件资料；已有源导出大量采用约1200 kg/m3的密度，因此不能把“exact_mesh”当作材料正确的证明。
3. 先核对一侧完整组件。用户确认的每侧5.14 kg含轮、电机和链条；整机15 kg，不把组件重复相加。这些总量约束分配，但不唯一确定各连杆质量。
4. CAD可输出质量、COM和COM处惯量。填表前转换到对应MJCF刚体局部坐标，惯量单位kg m²。不能将世界原点惯量直接当COM惯量，不能只填一个标量。
5. 左右几何、材料和装配一致后可镜像复用经过确认的一侧物性。COM坐标和惯量交叉项需要坐标变换，另一侧附件差异仍独立计入。

不能拆分称重的组件可以先做装配级质量/重心核对，然后结合已知材料和零件归属恢复分布；没有可识别的惯量依据时继续保留未核实状态。不要把源模型质量整体乘系数作为“已校准真实模型”。

## 气弹簧不靠厂家也能测什么

- 无需压缩即可记录：标识、两端安装体、销轴位置、可见杆径/缸径、当前两眼中心距和组件质量。修正模型已从真实CAD恢复两端销轴和伸缩轴，可与实物逐项对照。
- 自由伸长中心距、允许压缩中心距及实际工作行程应有真实记录。不要由“95×65”推断长度或行程。
- 力长曲线需要适合该负载的固定试验装置、轴向测力及位移测量；分别记录缓慢压缩、缓慢回伸，必要时记录不同速度。不要徒手、靠体重、夹持光杆或拆开气弹簧试测。没有合适装置时由具备条件的机械测试人员测量。
- 450 N只保留为已提供标称力，不能当作450 N/m刚度，也不能默认全行程恒定450 N；阻尼和摩擦/回差分开辨识。
- 若暂时无法获得力学数据，继续做固定基座的CAD运动回放、接口检查；不将无力气弹簧的诊断副本用于本次要求的真实动力学训练。

## 仍需在实机逐通道测量

零位、方向、反馈轴/比例、实际安全角度/速度/输出力矩范围、IMU安装和控制时序，继续填写configs/robot/hardware_calibration.yaml。左右对称不能代替编码器安装标定。顺序仍是模型运动核验 → 动力学修正与站立训练 → 板端输出一致性 → 架空限力 → 保护落地。
