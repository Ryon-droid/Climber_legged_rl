## 下一轮调整

第22轮配置：configs/robot/cad_getup_stand_round22_guarded_balance.yaml。目标仍是困难站姿，不增加推力，不放宽现有5 cm终态位置、朝向、低速和姿态标准。

1. 将原12个困难训练种子加入独立于普通组的选模检查，关闭随机推力。普通起身/站姿成功率仍优先，随后比较困难站姿成功率，再比较受推组与奖励。此前困难种子参与抽样，却没有直接进入best评分。该问题可能掩盖困难组变化，但不是已证实的失败唯一原因。
2. PPO完整更新没通过起身保护时，依次尝试原参数到候选参数之间1/2、1/4、1/8幅度的actor更新，每次都跑相同完整无扰起身检查。通过才保留，否则精确恢复原actor；critic学习保留。缩小更新后清除对应actor优化器动量。旧配置默认仍直接撤回，只有第22轮启用三次缩步。
3. 腿动作探索标准差保持0.005，轮子0.02增至0.05，增加平衡动作探索。电机控制映射、力矩、速度限制没有改变。
4. 从第21轮best继续，请求120000步，8环境通常实际122880步。其余困难抽样40%、受推概率25%、2–15 N混合推扰、成功轨迹回放及起身保护保留。继续使用已校验的36000条成功轨迹回放，不将失败硬组当作成功示范。

新增检查与缩步均仅用于训练和选模，运行时仍是单actor输出六电机动作，没有辅助动作接管。本轮是修正学习流程的实验，不能保证下一轮必然解决困难站姿；后续必须用新种子独立复测。若困难组仍2/12且随机组仍无配对提升，应继续排查动作探索、奖励和初始状态，避免只累加步数。
