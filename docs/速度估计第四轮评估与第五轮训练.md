## 第五轮调整

配置：`configs/robot/cad_balance_estimator_round5.yaml`。起身和估计器继续冻结，采用第四轮 best；保留现有困难推扰采样、恢复奖励以及各组成功率优先选模。

| 参数 | 第四轮 | 第五轮 |
| --- | --- | --- |
| 总目标步数 | 120000 | **200000**，8 环境实际约 204800 |
| 每环境 rollout | 512 步 / 5.12 秒 | **1024 步 / 10.24 秒** |
| GAE lambda | 0.97 | **0.995** |
| PPO 学习率 | 5e-6 | **1e-6** |
| 四个关节的动作标准差 | 每个 0.0025 | **每个 0.005** |
| 两个轮子的动作标准差 | 每个 0.05 | **每个 0.1** |
| 困难站姿训练/选模样例 | 12 个 | **13 个，新增 261409** |

动作标准差是策略输出空间里的探索参数，电机力矩/转速限幅沿用现有设置。clip 仍为 0.01、target KL 仍为 0.0008、每次 1 epoch。继续使用 CPU 物理 8 环境、每 20000 步以 8 进程选模。

调整依据是：已知失败是在受推后约 1.5 秒才触地，而原有 `gamma × lambda = 0.999 × 0.97` 的 GAE 误差信号衰减较快，近似有效时长约 0.32 秒；lambda 改为 0.995 后约为 1.67 秒。更长 rollout 也减少推扰与随后倒地被采样边界分开的情况。这是改善奖励回传的尝试，并不证明原设置是失败的唯一原因。

第四轮 29 个已记录更新的 `approx_kl` 都高于配置目标，范围约 0.00086–0.02189。该指标包括用于 KL 提前停止判断的批次，不能据此声称所有这些梯度都已执行。第五轮降低学习率，并适度扩大探索分布，尝试减小单位更新相对分布的变化，同时让当前策略尝试更多恢复动作。

原有 20% 困难推扰重置概率、20% 的条件困难站姿重置概率、普通回合 40% 推扰概率、2–15 N 范围、50–100 ms 持续时间、八个扇区和垂直 ±15°均沿用第四轮。位置/航向保持验收、推扰暂态容许值及恢复期限也不放宽。seed 261409 从本次独立测试发现后被纳入第五轮训练与选模；下一轮应再次换种子评估泛化。
