## 第九轮：先模仿成功轨迹，再学习纠偏

教师来自上一轮辅助起身best：`outputs/mujoco_runs/cad_getup_stand_round7_handoff_20261029_155227/best/best_model.zip`。学生从第八轮best初始化，使用36输入、6输出的全策略环境。

训练包括成功轨迹采样、轨迹附近的观测变化，以及DAgger：在学生自己遇到的状态上查询教师动作，扩充训练集。采样期间的教师混合比例逐轮降到0；各阶段评估完全关闭教师。训练过程中的状态复制和合成编码器扰动只用于离线标签生成，真实学生评估按正常浮动基座物理步进。

教师与学生的起身动作定义不同，程序按PD增益、阻尼和力矩上限换算标签，而不是直接复制教师的原始六维输出。第九轮前1.02秒使用起身PD增益，此后切回站稳PD增益；这个增益包络不生成关节目标或轮速，六路动作始终来自学生模型。

物理质量、弹簧力、155–220 mm限位与成功阈值均保留，不加入推扰、移动或侧翻任务。该模型先专注于趴姿起身与结束时站稳；后续其他动作可以按用户的遥控器多模型方案分别训练。

## 下一轮训练命令

```bash
cd /root/gpufree-data/Climber_legged_rl
bash scripts/train_imitation_getup.sh
```

这是示范预训练与DAgger，不是直接续跑旧PPO。默认从最新有效候选继续，增加360 mm后展姿态的回放权重至2倍，同时保留另外两种姿态和站姿样本。先10,000次监督更新，再4轮各3,000次更新；优化日志显示本阶段预计剩余秒数。配置为 `configs/robot/cad_getup_stand_round9_imitation.yaml`，日志在 `outputs/cad_getup_stand_round9_imitation/`，每次独立保存一个带时间戳的运行目录。候选需胜过父模型的三姿态短测成绩才会替换，避免直接保存退化的最后一次更新。

`imitation_latest.json`记录该次训练保存的最佳候选、哈希、教师和评估结果。短评估为三种趴姿各6秒，只用于选候选，不代表已经通过20/60秒正式验收。PPO微调候选参数保留在配置中（20万步、学习率1e-5），本入口不会自动启动微调；先看纯学生复测结果。
