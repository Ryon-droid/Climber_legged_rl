## 强推压力测试

第六轮 best，各档 8×15 秒，种子 95200–95207；每回合 3 秒后只推一次，随机水平质心力，持续 0.1–0.2 秒。相同随机数、方向和持续时间，按档位缩放幅值。2 个初态在推力之前已跌倒，所有档位均只剩 6 个实际受推回合，须分开报告：

| 请求采样范围 | 全部 8 回合成功 | 实际受推回合成功 |
|---|---:|---:|
| 10–20 N | 3/8 | 3/6 |
| 20–40 N | 2/8 | 2/6 |
| 40–80 N | 0/8 | 0/6 |
| 80–120 N | 0/8 | 0/6 |

补测第六轮 final：10–20 N 为总成功 4/8、实际受推成功 4/7；20–40 N 为总成功 2/8、实际受推成功 2/7。仍不足以证明大推力可用。

另以 0.03–0.08 秒短脉冲测试第六轮 best，10–40 N 为 4/6、20–60 N 为 3/6、30–80 N 为 2/6（实际受推回合）；同样不是该完整区间的保证。力和持续时间应一起比较，冲量为每次实际推力×持续时间。实际幅值、量化持续时间和冲量均在 JSON 的 `push_events` 中保留。

**现有策略不能直接升级为 80–120 N 常规训练。**压力测试已经测到明显跌倒区间。下一轮先将峰值从 5 N 提高到 20 N，保留轻推和无推样本，第七轮完成后使用新种子分别复测无推扰与强制 2–20 N 推扰，建议至少各 30 回合，无推扰≥95%、受推总体≥90%且记录每次恢复；达标后再试 20–40 N，最后评估 40–80 N 和偏心碰撞。该门槛是训练课程选择，不是比赛认证。不能把峰值更高但极短的脉冲与较低但更久的推力当作同一难度。

当前扰动仍作用于主体质心、仅水平方向；不含偏心撞击力矩、真实对手接触、斜向或竖向撞击。这些比赛情形需要后续单独建模和验收，本次测试不构成比赛抗撞保证。

从第五轮 best 开始：与第六轮 final 的轻推通过数相同，但平均倾角约 0.44°（final 约 1.65°），保留该原地站姿基线并学习更强推扰。重置步数和探索标准差，不用本次短跑策略。以下命令执行一次；该命令所示第七轮已经完成，请勿重复执行同名 run-name。已在当前工作区完成构建和 smoke，如更改配置或环境代码，先重新执行文末准备命令。

```bash
cd /root/gpufree-data/Climber_legged_rl

  --backend cad-dynamics \
  --config configs/robot/cad_dynamics_round7_push.yaml \
  --warm-start outputs/mujoco_runs/cad_dynamics_midpoint135_round5_stationary_20261028/best/best_model.zip \

  --run-name cad_dynamics_midpoint135_round7_push_20261029 \
```
