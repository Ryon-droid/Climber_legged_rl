# 必须实测的零位、方向、限幅

数据文件：configs/robot/hardware_calibration.yaml。未测值保持null。历史固件偏置、导出器±1.57 rad与试训10/2 Nm不属于当前实机标定。编码器反馈必须对应当前MJCF坐标。

| 项目 | 六通道分别记录的内容 | 方法与依据 |
| --- | --- | --- |
| 通道身份 | 总线、ID、实物位置、模型joint | 单通道辨认并录像；顺序左前/左后/右前/右后/左轮/右轮 |
| 反馈轴/比例 | 转子/减速器输出/关节侧，单位、比例、回绕与多圈 | 无动力或低能量转已知角；核对9:1及268:17是否已被协议处理，额外链比20:20为1 |
| 零位 | 腿部q=0对应反馈角及安装姿态 | CAD/夹具建立可复现姿态，记录多圈参考；轮绝对相位不入策略但回绕/速度仍需验证 |
| 方向 | 模型正向、正反馈、正控制指令对应关系 | 架空逐路低限力点动；左右不能复制符号；另记录正前进时两轮模型速度符号 |
| 软限位 | 安全角度范围、闭链禁区、裕量 | 无动力确认边界后低力确认；虚拟腿长不是关节限位，轮通常连续转动 |
| 力矩/电流 | 连续/峰值输出力矩、峰值时长、电流换算、制动/再生约束 | 当前驱动协议和扭矩测量/可信参数、传动效率；20 Nm名称值不能直接作所有上限 |
| 转速与变化率 | 输出轴最大速度、加减速、指令变化率 | 架空逐步辨识留日志，首测低上限与最终包络分开 |
| IMU | 安装旋转、四元数顺序/方向、单位、偏置、重力符号 | 静止及绕三轴已知方向倾斜；base为x前/y左/z上 |
| 时序与失效 | 策略/底环周期、延迟分布、丢帧、看门狗、急停和断连输出 | 禁能验证输出后架空验证停机；记录固件/模型/策略哈希 |

反馈定义：q_model = direction * (q_feedback / feedback_to_joint_ratio - zero_feedback_rad)。zero_feedback_rad是模型q=0时的反馈角除以比例，不是直接照抄历史偏置。速度转换用同样比例和方向；力矩/电流换算按协议输出轴口径辨识。

板端一致性使用同一批输入和接口版本，报告每通道最大/均方误差及限幅前后输出。未完成CAN/驱动适配前，不宣称完成实机控制验证。核验脚本不发送硬件命令。

真实动力学训练另需：逐刚体质量/COM/惯量及零件归属，气弹簧数量/安装点/方向/行程/力长曲线/阻尼，轮胎有效半径/接触宽度及摩擦。它们与板端编码器标定是不同问题。
