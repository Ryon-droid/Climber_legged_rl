# Climber 训练上位机

从 GitHub 获取源码后，先将 `config.example.json` 复制为本目录的 `config.json`，填写训练设备、SSH 私钥绝对路径、远端仓库目录和 Python 环境路径，再从仓库根目录运行 `python3 training_console/server.py`。个人 `config.json` 不纳入版本管理。下文中的本机路径和桌面服务描述对应现有开发电脑；新电脑可直接运行上述服务入口，不需要预先创建桌面服务。

远端预览入口需将本目录的 `remote_preview.py` 同步为远端仓库的 `scripts/training_console_preview.py`。默认预览读取所选轮次协议中的站立力矩限值，新配置每台腿电机为 ±20 N·m，历史轮次仍按其原始设置回放。

在本机浏览器查看 2080 SUPER 上的轮腿训练状态、评估、日志，输入远端终端指令，并生成和播放当前策略的仿真录像。

启动：

```bash
python3 /home/lsx/wheel_leg/training_console/server.py
```

打开 <http://127.0.0.1:8765>。本机程序只使用 Python 标准库，不需要额外安装前端依赖。SSH 配置在 `config.json`，使用本机现有 SSH 密钥，不保存密码。服务只监听本机地址。

已在桌面添加“Climber 训练上位机”入口。双击后启动本机用户服务并打开浏览器；无需保持 Codex 对话或终端窗口开启。也可以运行 `python3 /home/lsx/wheel_leg/training_console/launch.py`。服务已设置为登录当前用户后自动启动，电脑重启并登录后可以直接打开页面。手动停止服务后，可再次双击桌面入口启动。

界面每 5 秒读取一次训练状态。对照训练按各分支的已写入日志和检查点计算总采样进度，其他历史实验沿用已完成回合的下限或已保存进度；预算使用百分比不代表目标完成百分比。剩余时间依据已用时间、采样进度和评估预留粗略估算，评估期间会波动；设备离线或任务停止时不继续倒计时。

学习曲线包括选模成功率、平均回合奖励、平均回合时长、训练成功率、近似 KL 和价值预测误差。各分支使用各自从零开始的采样步数，绿色与蓝色分别对应图例中的两组；单击图例可切换显示，悬停可查看实际记录。选模图可切换固定 18 N、随机推扰、站立和困难起身，虚线为同场景父模型基线，橙色描边标记被保留检查点。训练曲线读取每组 CSV 原始值，缺失值不补零；长记录最多抽取约 500 点并保留最新一点。

训练回合成功率是日志中的滚动统计，训练奖励使用 0.01 缩放；不能与选模或独立测试成功率混为一谈。表格区分选模成绩和本轮结束后的独立验收；训练中显示保留模型，不用最后被拒绝候选的成绩冒充最佳成绩。当前轮腿训练使用 CPU 并行 MuJoCo/PPO，显存空闲并不代表程序停止。

点击“连接终端”后得到独立的远端交互式终端，初始位于训练仓库，已准备好训练 Python 环境。输入指令后 Enter 执行，Shift+Enter 换行，上下箭头查看本次会话历史。“中断当前命令”只向这个终端的前台命令发送 Ctrl+C，不会停止后台训练。查看当前状态和日志的快捷按钮先填入指令，再按 Enter 执行。

点击“生成当前策略预览”会复制该实验当前保留模型的快照，在真实的 208 mm 机器人模型中录制一个独立回合，传回本机播放。可选站立或趴姿、0～150 N 推力及随机种子。0 N 表示无推力，非零为原有的 0.05～0.10 秒短脉冲。回合失败也会如实展示，单段录像不代表整体成功率。录像、模型指纹和实测轨迹保留在远端 `outputs/training_console_previews`，本机视频缓存在 `cache`。

远端录像入口为 `scripts/training_console_preview.py`，其源文件为本目录的 `remote_preview.py`；已安装到当前训练设备。更换设备时需同步此文件。历史视频按原路径标注，不作为当前模型演示。终端可运行远端脚本；无桌面的远端建议使用录像入口查看仿真。

关闭本机服务不影响后台训练。无需额外开启远端端口；访问、终端和视频传输均通过现有 SSH 连接。训练不会被本界面自动启动、停止或部署到实机。
